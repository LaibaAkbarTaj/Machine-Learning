# Linear Regression Model

This folder contains the implementation of a Linear Regression model using Python.

## 📁 Files Included
- `linear_regression.ipynb`: Notebook containing data loading, model training, evaluation, and visualization.
- `data.csv`: The dataset used for training and testing.

## 📊 Overview
1. **Data Preprocessing:** Loading data via Pandas and handling features.
2. **Model Training:** Fitting data using Scikit-Learn's LinearRegression.
