# Polynomial Regression Model

This folder contains the implementation of a Polynomial Regression model for non-linear data.

## 📁 Files Included
- `polynomial_regression.ipynb`: Notebook covering polynomial feature transformation and model fitting.
- `data.csv`: Dataset used for model evaluation.

## 📊 Overview
1. **Feature Transformation:** Transforming features using Scikit-Learn's PolynomialFeatures.
2. **Model Training:** Fitting a linear model on transformed features.
3. **Visualization:** Plotting non-linear regression curve against dataset points.
